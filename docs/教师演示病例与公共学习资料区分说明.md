# 教师演示病例与公共学习资料：视觉与文案区分

两个模块数据本来就不同源（`biz_teaching_share` / `biz_learning_resource`），本次只改前端展示，不动表结构、接口和权限。

## 对照表

| 维度 | 教师演示病例 | 公共学习资料 |
|---|---|---|
| 页面 | `views/training/student-teaching.vue` | `views/learning/index.vue` + `components/ResourceCard.vue` |
| 主色 | 蓝 `#1677ff`（卡片顶边 + 徽标） | 橙 `#fa8c16`（卡片顶边 + 徽标） |
| 左上角徽标 | 「教师演示病例」 | 「公共学习资料」 |
| 次级标签 | 「入库教学 / 临时分享」 | 资料分类（浅色小标签，不再给整卡上色） |
| 封面 | 眼底缩略图（`imagePaths` 首张，优先 OD→OS），多图显示「共 N 张」；无图 / 加载失败显示占位 | 有封面用封面；否则按文件格式显示图标：PDF / 课件 / 图片 / 视频 / 文章 |
| 主按钮 | 「开始判读」（有关联实训病例时），否则「查看详情」 | 「去阅读」 |
| 次按钮 | 「查看详情」 | 关联了病例时显示「去判读这个病例」→ `/training/reading?caseId=` |
| 筛选 / 排序 | 病种、分级、难度；最新分享 / 难度由低到高 / 由高到低 | 最新 / 最多阅读 / 最多收藏（对当前页排序） |
| 空状态 | 「老师还没给你分享病例，分享后会出现在这里。」；筛选无结果时提示并给「清除筛选」 | 「暂无资料，可以换个关键词或分类试试。」 |

## 分类改名（仅显示）

- `CASE_TEMPLATE` 显示为「病例解读（文档）」，筛选下拉、卡片、预览弹窗一致；库里的枚举值和筛选参数不变。
- 没有分类的历史资料显示为「知识点文档」。
- 统一入口：`api/learning.ts` 的 `resourceTypeLabel()`。

## 说明

- 未公布结论（`answersRevealed === false`）的病例不参与「分级」筛选，避免通过筛选结果反推答案。
- 老师端「我的教学分享」页未改动。

## 验收步骤

1. 学生账号打开「教师演示病例」：卡片顶部为蓝色边、左上角「教师演示病例」，有眼底图的显示缩略图，多图显示「共 N 张」。
2. 依次选病种、分级、难度，列表随之过滤；切换排序后顺序变化；无结果时出现「清除筛选」。
3. 有关联实训病例的卡片主按钮为「开始判读」，点击进入判读页。
4. 打开「公共学习资料」：卡片顶部为橙色边、左上角「公共学习资料」，旁边是分类小标签，没有蓝色卡片。
5. 分类下拉和卡片上不再出现「病例范本」，而是「病例解读（文档）」。
6. 关联了病例的资料卡出现「去判读这个病例」，点击进入对应病例判读页。
7. 切换「最多阅读 / 最多收藏」排序，当前页按阅读数 / 收藏数降序。
