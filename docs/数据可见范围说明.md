# 数据可见范围说明（笔记 / 收藏 / 学习记录）

## 1. 问题与根因

管理员打开「学习资料与笔记 → 我的笔记」时，能看到全部学员的笔记。

- `LearningService.list_notes` 对管理员不按 `user_id` 过滤（查询未按当前用户过滤）。
- 「我的笔记」和管理用途共用同一个页面和接口 `GET /learning/notes`（入口复用）。
- 详情、编辑、删除也允许管理员操作他人笔记，而且没有操作记录（权限未隔离）。

## 2. 修复后的规则

| 数据 | 学员 | 教师 | 管理员 |
|---|---|---|---|
| 我的笔记 `GET /learning/notes` | 仅本人 | 仅本人 | 仅本人（传入的 `userId` 参数会被忽略） |
| 笔记详情 / 编辑 / 删除 `/learning/notes/{id}` | 仅作者本人 | 仅作者本人 | 仅作者本人；操作他人笔记返回 403 |
| 笔记审核视图 `GET /learning/admin/notes`、`/learning/admin/notes/{id}` | 403 | 403 | 可查看全部笔记，**只读**，每次访问写操作日志 |
| 我的收藏 `GET /learning/favorites` | 仅本人 | 仅本人 | 仅本人（原本即如此，未改动） |
| 练习记录 / 判读记录 | 仅本人 | 可查看全部学员（用于审核、带教） | 可查看全部 |

### 审核视图的操作日志

- 写入 `biz_op_log`，`module = learning`。
- 查看列表：记录访问人、时间和筛选条件。
- 查看详情：`action = note.admin_view`，`detail` 内容为「审核视图查看笔记 #ID《标题》作者 姓名(id=…)」。
- 在「平台管理后台 → 操作日志」中可以查到。

### 前端入口

- **「我的笔记」**：页面没有改动，后端修复后只显示本人的笔记。
- **「笔记管理（审核视图）」**：新页面，路由 `/training/admin-notes`，仅管理员可见、可访问（路由 `allowedRoles: ['admin']`，后端同样校验）。
  - 菜单位于「管理与设置」下。
  - 页面顶部固定显示「他人笔记 · 审核视图，访问将被记录」。
  - 每条笔记都标出作者姓名和 ID。
  - 只有「查看」操作，没有编辑或删除按钮。

## 3. 自动化测试

`backend/tests/test_learning_note_isolation.py`

- `test_every_role_only_sees_own_notes_in_my_notes`：学员、教师、管理员在「我的笔记」中都只能看到自己的笔记。
- `test_admin_user_id_param_is_ignored_in_my_notes`：管理员给「我的笔记」传 `userId` 无效。
- `test_others_cannot_read_edit_or_delete`：任何角色都不能读取、修改、删除他人笔记。
- `test_owner_can_still_read_edit_delete`：作者本人可以正常读取、修改、删除。
- `test_admin_view_rejects_non_admin`：学员和教师调用审核接口返回 403。
- `test_admin_view_lists_others_and_writes_audit_log`：管理员能在审核视图看到他人笔记，并且写入了操作日志。

## 4. 手动验收步骤（在你们的环境中执行，并截图存档）

1. 学员 A 新建笔记「A 的笔记」，学员 B 新建笔记「B 的笔记」。
2. 学员 A 登录 → 我的笔记：只看到「A 的笔记」。学员 B 同理。
3. 学员 A 在地址栏或接口中直接访问 B 的笔记 ID：返回 403。
4. 教师登录 → 我的笔记：只看到自己的笔记；侧边栏没有「笔记管理（审核视图）」；直接访问 `/training/admin-notes` 会被拦截。
5. 管理员登录 → 我的笔记：只看到管理员自己的笔记。
6. 管理员 → 管理与设置 → 笔记管理（审核视图）：能看到 A 和 B 的笔记并带作者标识；打开详情只能看，不能改。
7. 平台管理后台 → 操作日志：能查到第 6 步的访问记录（`note.admin_view`）。
8. 收藏：A 和 B 各自收藏不同资料，互相看不到对方的收藏。

## 5. 影响与待办

- 管理员如果之前在「我的笔记」里查看全员笔记，以后要改用「笔记管理（审核视图）」。
- **待办（本轮未改）**：教师目前能看到全部学员的练习和判读记录，学员判读审核、全班统计等页面依赖这一点。后续可以收紧为只看本人带教组（`mentor_group`）的学员，需要同时调整审核流程。
