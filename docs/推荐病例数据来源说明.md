# 推荐病例数据来源说明

适用页面：带教医师首页 →「任务与病例布置」→「推荐病例」（`frontend/src/views/training/home.vue`）。

## 1. 数据来源

| 项目 | 说明 |
|---|---|
| 接口 | `GET /rotation/options` |
| 后端 | `RotationService.options()`（`backend/app/services/rotation_service.py`） |
| 表 | `biz_training_case` |
| 权限 | 带教医师、管理员；学员返回 403 |

返回字段：

- `cases`：可推荐病例，每项含 `id`、`label`（编号 · 标题）、`category`（病种）、`difficulty`（难度）、`goldDrGrade`（金标准 DR 分级）。
- `pendingCases`：**当前登录教师本人创建**、但还不能推荐的病例，额外含 `isPublished`、`isTrainCase`、`missingStep`（`未发布` / `未开放练习`）。其他教师的草稿不会返回。

## 2. 准入条件（本次未改）

一例病例要出现在「可推荐」里，必须同时满足：

1. `is_published = 1`（已发布金标准）
2. `is_train_case = 1`（已开放给全体学员练习）
3. `archive_status = ACTIVE`（未归档）

这与学员端能打开病例的条件一致，所以推荐出去的病例学员一定打得开。`POST /rotation/tasks` 会再次校验。

## 3. 各上传方式的默认状态

| 上传方式 | 进库后 | 能否直接推荐 |
|---|---|---|
| 病例库上传登记表（`/case-browse/import`） | 未发布、未开放练习 | 否，进入「待处理」 |
| AI 建病例 | 未发布、未开放练习 | 否，进入「待处理」 |
| 管理员 IDRiD 导入 | 已发布、已开放练习 | 是 |
| 提交公共教学库、审核通过后的 T 开头副本 | 已发布、已开放练习 | 是 |

## 4. 上传到可推荐的流程

```
上传病例（登记表 / AI 建病例）
        │  状态：未发布 → 下拉中灰显「未发布」
        ▼
病例库 → 完善金标准 → 发布
        │  状态：已发布、未开放练习 → 下拉中灰显「未开放练习」
        ▼
病例库 → 开放给全体学员练习
        │  状态：可推荐
        ▼
首页「推荐病例」下拉选中 → 选必做/拓展、对象 → 标记推荐
```

「开放练习」不会再顺带发布，两步必须分开做。

## 5. 页面交互

- 下拉上方有 **病种 / 难度 / DR 分级** 三个筛选，同时作用于可推荐和待处理两组。
- 下拉分两组：「可推荐」可选；「我的待处理病例（不可选）」灰显，右侧标出还差哪一步。
- 有待处理病例时显示提示条：「你还有 N 例病例未开放练习」，可跳转病例库。
- 没有任何可推荐病例时显示空状态和「去病例库」按钮。
- 筛选旁的「找不到？去上传 / 管理病例」跳转 `/training/cases`。

## 6. 验收步骤

1. 以带教医师登录，在病例库上传一份病例登记表。
2. 回到首页，打开「选择病例」下拉：新病例出现在「我的待处理病例」组，灰显，标注「未发布」；提示条显示待处理数量。
3. 在病例库完善金标准并发布：下拉中该病例标注变为「未开放练习」。
4. 在病例库点「开放给全体学员练习」：该病例移入「可推荐」组，可以选中。
5. 用病种 / 难度 / DR 分级筛选，确认该病例按字段正确出现或隐藏。
6. 选中后点「标记推荐」，任务表中出现该任务，目标学员首页可见。
7. 用另一位教师登录：看不到第 1 步上传的草稿病例。
