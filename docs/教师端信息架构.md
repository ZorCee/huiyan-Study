# 教师端信息架构（菜单与命名）

适用角色：带教医师（doctor）、管理员（admin）。学员、患者端菜单不变。

## 1. 改造后的菜单树

```
教学看板            学情分析、任务与病例布置（"待审概况"改为跳转到作业批阅）
教学
  ├ 作业批阅（待审徽标）    /training/reading?tab=review
  ├ 正式考核与试卷          /training/exams
  └ 教学分享                /training/teaching-share
病例与影像
  ├ 病例中心（检索库 + AI 智能建案）  /training/cases
  ├ 双眼阅片工作台          /training/reading
  └ AI 批量筛查             /training/screening（在教师门户内打开）
管理与设置
  ├ 班级与学员维护          /training/class
  └ 平台管理后台（仅管理员） /training/admin
学习与个人                  学习资料与笔记 / 通知 / 个人中心
```

所有分组默认展开，主要功能 1 次点击可达；侧栏折叠时最多 2 次。

## 2. 解决的问题

| 问题 | 处理 |
|---|---|
| 教学分享放在病例中心的标签里 | 独立成路由，移入「教学」 |
| AI 批量筛查放在「教学事务管理」，点击后切到筛查门户、教师菜单消失 | 移入「病例与影像」，在教师门户内打开 |
| 「教学事务管理」名不副实 | 拆分：考试进「教学」，班级进「管理与设置」 |
| 平台管理后台单独一组 | 并入「管理与设置」 |
| 看板「待审概况」与侧栏「作业批阅」重复 | 看板改为一行待审数 + 跳转按钮 |
| 同一功能多种叫法 | 见第 3 节 |
| 筛查门户「病例检索」与病例中心「病例检索库」同名不同源 | 筛查门户内改名「筛查记录检索」 |

## 3. 命名对照（菜单 = 页面标题 = 学员端）

| 旧叫法 | 统一为 |
|---|---|
| 病例浏览检索 / 病例库（学员端） | 病例中心 |
| 影像阅片工作站 / 阅片工作台（学员端） | 双眼阅片工作台 |
| 正式考试 | 正式考核与试卷 |
| 班级学生 | 班级与学员维护 |
| 我的教学分享 | 教学分享 |
| 学情监控与督学 | 学情分析 |
| 筛查门户「病例检索」 | 筛查记录检索 |

约定："分析"指学情和成绩分析；"质控"只指图像质量。

本期已统一：侧栏菜单、教师端页面标题（考试、班级、教学分享、筛查记录检索）、看板标签。学员端练习页里的「正式考试」卡片标题暂未改，避免学员端出现"试卷"字样。

## 4. 旧路径迁移

| 旧路径 | 新路径 |
|---|---|
| `/training/cases?tab=my-shares` | `/training/teaching-share`（其他查询参数保留） |
| `/training/teaching-share` | 不变，直接打开页面（原来跳到病例中心） |
| `/screening`、`/screening/dashboard` | `/training/screening` |
| `/screening/profile` | `/training/profile` |
| `/screening/list` | 保留（筛查记录与病例库数据源不同，合并需单独排查） |

权限不变：新路由 `/training/screening` 限 admin、doctor，与原 `/screening`（拒绝 trainee、patient）一致。后端接口未改。

## 5. 验收步骤

1. 教师登录，侧栏显示「教学 / 病例与影像 / 管理与设置 / 学习与个人」四组，全部展开。
2. 点「教学分享」，地址为 `/training/teaching-share`，侧栏高亮「教学分享」；病例中心只剩「病例检索库」「AI 智能建案」两个标签。
3. 点「AI 批量筛查」，左栏仍是教师菜单，地址为 `/training/screening`，能正常上传。
4. 浏览器直接打开 `/screening`、`/training/cases?tab=my-shares`、`/screening/profile`，分别跳到新路径。
5. 管理员能在「管理与设置」看到平台管理后台；带教医师看不到。
6. 学员登录，侧栏为「病例中心」「双眼阅片工作台」，访问 `/training/screening`、`/training/teaching-share` 被拦回首页。
7. 教学看板只有「学情分析」「任务与病例布置」两个标签，下方「去作业批阅」可跳转。
