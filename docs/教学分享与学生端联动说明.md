# 教学分享 → 学生端「教师演示病例」联动说明

## 数据链路

老师端「我的教学分享」分享或入库 → 写入 `biz_teaching_share`（脱敏快照）→ 学生端 `/training/student-teaching` 通过
`GET /teaching/student/cases` / `GET /teaching/student/cases/{id}` 读取。

## 学生可见条件

| 类型 | 可见条件 | 范围 |
|---|---|---|
| 临时分享 `TEMPORARY` | 状态 `SHARING`，且 `expired_at` 为空（长期有效）或晚于当前时间 | 全体 / 年级 / 轮转批次 / 带教组 / 指定学员 |
| 入库教学 `PERMANENT` | 仅 `APPROVED` | 全体（按设计不分范围；定向发放请用临时分享） |

`PENDING` / `REJECTED` / `SHELVED` / `REVOKED` / 已过期均不可见；范围外学生直接访问详情返回 403。

## 本次新增

- **长期有效**：分享弹窗勾选「长期有效」时 `expireHours = 0`，`expired_at` 为空，直到老师手动收回。
- **修改 / 续期**：`POST /teaching/share/{id}/update`（仅分享者本人，仅 `TEMPORARY` + `SHARING`）。
  可改范围、指定学员、有效期；有效期从保存时刻重新计算，已过期的分享可借此续期。
- **老师自行下架**：`POST /teaching/share/{id}/shelve`（仅分享者本人，仅 `PERMANENT` + `APPROVED`），复用管理员下架逻辑。
- **学生端同步**：页面在 keep-alive 下每次切回都重新拉取，可见时每 60 秒轮询一次。
- 老师端列表显示「长期有效」，已过期的分享提示「学员端不可见」并提供「续期」按钮。

## 验收步骤

1. 老师 A 对某病例「分享」，范围选「按带教组 = 甲组」，勾选长期有效。
2. 甲组学生打开「教师演示病例」：能看到；乙组学生：看不到。
3. 老师 A 点「修改」把范围改为「全体学员」→ 乙组学生切回页面（或等待 ≤60 秒）即可看到。
4. 将有效期改为 1 小时并等待过期 → 学生端消失；老师端显示「已过期」，点「续期」后重新出现。
5. 老师「收回」→ 学生端消失。
6. 入库申请经管理员通过 → 全体学生可见；老师点「下架」→ 学生端消失。
